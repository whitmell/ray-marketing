# Ray Matthews Marketing Pipeline

Automated marketing pipeline for Ray Matthews fine art photography. The static
frontend uses a serverless AWS backend.

## Development and deployment

See [README.md](README.md) for the architecture, local frontend preview,
deployment, and environment configuration. There is no `npm run dev`,
`npm start`, local backend, or Docker setup in this version.

- `npm run build` bundles the Lambda handlers with esbuild.
- `frontend/` contains the static SPA; `frontend/config.js` is generated by
  deployment scripts and ignored by Git.
- `src/lambda/` contains the API Gateway and pipeline Lambda handlers.
- `src/data/` and `src/services/` contain the DynamoDB/S3 data layer and
  application services.
- `infrastructure/` contains the CloudFormation template and PowerShell
  deployment scripts.

The deployed dashboard uses Cognito authentication, DynamoDB, S3, API Gateway,
Lambda, and CloudFront. Local frontend requests are not automatically routed to
these services.
